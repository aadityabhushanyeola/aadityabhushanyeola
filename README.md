## Featured Projects 💻

### Autonomous Rover Software System
**Autonomous Rover Software System** is a full-stack robotics software suite built with **ROS 2, OpenCV, YOLOv8, and Python**. This project demonstrates my ability to architect state-machine based autonomous behavior, integrating real-time computer vision pipelines for arrow detection, obstacle recognition, and scene understanding alongside depth camera data for mapping and localization.

### Real-Time Sensor Data Pipeline
**Real-Time Sensor Data Pipeline** is a hardware-to-software communication system built with **Python, PySerial, and ROS 2**. This project showcases my skills in designing publisher-subscriber architectures for asynchronous sensor data processing, enabling real-time motion control and navigation in robotics systems.

### Long-Range Telemetry & Video Streaming System
**Long-Range Telemetry & Video Streaming System** is a wireless communication system built with **ROS, GStreamer, and custom telemetry protocols**. This project demonstrates my ability to engineer reliable data transmission across a **9 km non-line-of-sight wireless network**, including live camera streaming for remote robot diagnostics.

### MQTT-Based Distributed Communication System
**MQTT-Based Distributed Communication System** is a lightweight distributed messaging architecture built with **MQTT and Python**. This project showcases my skills in designing scalable data streaming pipelines for transmitting environmental sensor data across networked robotic systems.
